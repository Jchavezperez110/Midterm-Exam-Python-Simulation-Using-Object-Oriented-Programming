# Midterm-Exam-Python-Simulation-Using-Object-Oriented-Programming
# JJBA Character Roster Simulator
# Pseudocode

1. Start the program.
2. Create five JJBA character objects.
3. Display the main menu.
4. Ask the user to choose an option.

5. If the user chooses Show Characters:
   - Display the character roster.

6. If the user chooses View Character:
   - Display the roster.
   - Ask the user to choose a character.
   - Display the character's name, Stand, and power.
   - If the selection is invalid, display an error.

7. If the user chooses Use Stand Ability:
   - Display the roster.
   - Ask the user to choose a character.
   - Display the character using their Stand ability.
   - If the selection is invalid, display an error.

8. If the user chooses Exit:
   - Display a goodbye message.
   - End the program.

9. Repeat the menu until the user exits.
